# 学习日历 V2

“学习日历”是一款面向手机竖屏、完全离线的学习任务管理 App。V2 在 V1 月历基础上加入按日期管理的“新任务专区 / 复习专区”、任务内容卡片、验收与掌握度，以及一次性的 2、3、7 天间隔复习。

## 运行方式

- 环境：Android Studio、JDK 17 或更高版本、Android SDK Platform 37.2。
- 在 Android Studio 中打开当前项目目录，等待 Gradle 同步后运行 `app`。
- 命令行验证：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

- 如从 V1 工作区升级后首次出现 Room 生成类缺失，执行一次 `.\gradlew.bat clean` 后再构建。
- 已生成的 V2 安装包：项目根目录下的 `学习日历-V2-debug.apk`
- 标准 APK 输出：`app/build/outputs/apk/debug/app-debug.apk`
- 使用 ADB 安装：

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## V2 功能

- 保留 V1 的当前月、今天标记、日期选择、月份滑动/按钮切换和“回到今天”。
- 点击日期后，在月历下方按时间顺序展示当天全部任务；每个任务独立成框，可继续进入当天任务页。
- 月历支持展开和收起；收起后显示月份标题、展开按钮以及选中日期所在的一整周日期。
- 当天页面依次展示复习卡片专区、新任务卡片专区，以及位于最下方的已完成卡片专区。
- 复习与新建专区均支持卡片新增、读取、编辑、删除和完成。
- 月历圆点数量统计新任务与复习任务的总数。
- 任务详情按创建顺序展示纵向连续内容卡片，新卡片固定在底部。
- 每张内容卡片包含卡片目标、初始动作、验收标准，并支持展开、编辑和删除。
- 验收详情支持完成/取消完成，以及 0–4 五级掌握度；0 是有效已选状态。
- 原始任务完成后可开启 2、3、7 天复习；自动复习任务和手动复习任务不能继续派生复习链。
- 任意卡片标记完成后自动移入最下方的“已完成卡片专区”；取消完成后返回卡片原本所属专区。
- 右下角深色圆形加号可新建今天的任务卡片，标题与时间使用可滚动的底部大面板编辑，点击外部可返回日历。
- 界面统一使用“任务卡片 / 内容卡片”术语；日历预览卡片中可直接切换完成状态和间隔复习。
- 任务卡片上的“已完成 / 标记完成”和“添加到间隔复习”在同一行展示。
- 验收页可在验收标准下方添加学习快照，支持系统照片选择器和音频文件选择器。
- 快照文件复制到 App 专属 `学习快照` 目录，目录不存在时自动创建；无需存储权限。
- 所有 CRUD、完成状态、掌握度和复习链均持久化到本机 Room 数据库。

## 数据模型

- `StudyTaskEntity`
  - 稳定 UUID；标题；日期；可选时间；专区；任务完成状态；是否开启间隔复习；系统创建日期与创建时间。
  - 来源类型：原始任务、自动复习任务、手动复习任务。
  - 自动复习任务保存 `sourceTaskId + reviewSequence`，数据库对两者建立唯一索引。
- `TaskContentCardEntity`
  - 任务外键、三个内容字段、创建时间、稳定 `sortOrder`、验收完成状态、可空掌握度。
  - 编辑不会改变 `sortOrder`；任务或卡片删除时使用外键级联。
- `LearningSnapshotEntity`
  - 关联内容卡片，保存照片/录音类型、原文件名、App 内相对路径和创建时间。
- Room 数据库升级到版本 2，并提供版本 1 → 2 的非破坏性迁移。
- `AppMetadataEntity`
  - 记录 V2 示例数据是否已经初始化，避免用户清空任务后重新启动又被填入示例。

DAO 负责查询与更新，`RoomStudyTaskRepository` 负责事务和领域转换。UI 只通过 Repository 与 ViewModel 接收 Flow 数据。

## 间隔复习规则

创建当天算第 1 天：

| 复习序号 | 日期 |
|---:|---|
| 第 2 天 | 原始任务创建日期 `D + 1` |
| 第 3 天 | 原始任务创建日期 `D + 2` |
| 第 7 天 | 原始任务创建日期 `D + 6` |

开启复习时，在一个 Room 事务中：

1. 标记原始任务已开启复习并移动到复习专区；
2. 创建缺失的第 2、3、7 天任务；
3. 将源任务标题、时间和内容卡片按原顺序复制为独立快照；
4. 若记录已存在则复用，避免重复生成。

关闭复习、取消已完成状态和删除原始任务都会清理关联自动复习任务；删除单个自动复习任务只影响当前实例。

## 主要文件

- `domain/CalendarDateLogic.kt`：V1 月历日期网格与月份逻辑。
- `domain/ReviewSchedule.kt`：2、3、7 天自然日计算。
- `domain/StudyModels.kt`：任务、分区、来源和掌握度模型。
- `data/local/`：Room Entity、DAO 与数据库。
- `data/local/LocalSnapshotStorage.kt`：照片/录音复制、App 文件夹创建与文件清理。
- `data/RoomStudyTaskRepository.kt`：事务、幂等复习链、级联和示例初始化。
- `di/AppContainer.kt`：数据库与数据层依赖装配。
- `ui/LearningCalendarApp.kt`：月历、当天任务、任务详情、验收详情导航。
- `ui/day/`：两个专区的任务 CRUD、完成和复习入口。
- `ui/detail/`：连续时间线内容卡片与固定添加按钮。
- `ui/acceptance/`：验收完成和五级掌握度。

## 荣耀手机竖屏与无障碍

- 竖屏锁定，系统栏使用 edge-to-edge 与 `WindowInsets.safeDrawing` 避让状态栏、屏幕圆角和手势导航。
- 内容页使用可滚动 `LazyColumn`；任务详情底部固定添加按钮额外避让导航手势区域。
- 日期触控单元与其他点击入口均至少 48dp。
- 360dp 宽度下日期列仍不小于 48dp，兼容 360–430dp。
- 长标题、日期、时间、验收文本和卡片字段不限单行，可在窄屏/大字体下换行增高。
- 任务完成、复习状态和验收状态使用文字与控件双重表达，不只依赖颜色。
- 日期、任务完成、间隔复习、编辑、删除、验收详情和五级掌握度均提供中文无障碍语义。
- 新页面提供 360dp 和 1.8 倍字体缩放 Compose Preview。
