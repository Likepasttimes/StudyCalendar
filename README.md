# 学习日历 V2.7.0

“学习日历”包含 Android 手机端和 Windows 桌面端。Android 端继续提供任务、验收、复习、学习快照、周总结和错误记录；Windows 端采用左侧导航、右侧内容的宽屏布局，并可接收手机主动推送的完整本地数据快照。两端之间只在同一局域网内直连，不接入账号、云盘或第三方后端。

## 运行方式

- Android 环境：Android Studio、JDK 17 或更高版本、Android SDK Platform 37.2。
- 在 Android Studio 中打开当前项目目录，等待 Gradle 同步后运行 `app`。
- Android 安装包统一保存在 `Android安装包` 文件夹。
- 已生成的 V2.7.0 安装包：`Android安装包\学习日历-Android-V2.7.0-debug.apk`
- 标准 APK 输出：`app/build/outputs/apk/debug/app-debug.apk`
- 使用 ADB 安装：

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

- Windows 软件统一保存在 `Windows安装包` 文件夹。
- Windows 推荐安装版：运行 `Windows安装包\学习日历-Windows-V1.4.1-安装程序.exe`，按提示完成安装。安装过程中可选择数据保存位置；程序会安装到固定的用户程序目录，并创建开始菜单和桌面快捷方式。
- 以后升级时直接运行新版安装程序，无需先卸载旧版，也不需要手动解压或移动程序。
- Windows 便携版备用：解压 `Windows安装包\学习日历-Windows-V1.4.1.zip`，运行 `学习日历\学习日历.exe`。
- Windows 首次启动如出现防火墙提示，请允许专用网络访问，否则手机无法连接。
- 手机与电脑必须连接同一 Wi-Fi。打开 Windows 版“电脑同步”，在手机底部进入“电脑同步”，填写电脑地址、端口和 6 位配对码，再点击“同步全部数据到电脑”。
- Windows 安装版与便携版使用同一份用户数据目录。升级、切换安装版或重新运行安装程序都不会删除已同步数据。
- 数据保存位置在安装向导中单独选择，默认优先建议 `D:\学习日历数据`；也可以选择其他非 C 盘文件夹。

- 命令行验证：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
.\gradlew.bat :windowsApp:test :windowsApp:windowsFatJar
.\package-android.ps1
.\windowsApp\package-windows.ps1
```

- 后续 Android 版本运行 `package-android.ps1`，APK 会按版本号写入 `Android安装包`。
- 后续 Windows 版本运行 `windowsApp\package-windows.ps1`，安装程序和便携包会按版本号写入 `Windows安装包`。

- 如从 V1 工作区升级后首次出现 Room 生成类缺失，执行一次 `.\gradlew.bat clean` 后再构建。

## Android 功能

- 保留 V1 的当前月、今天标记、日期选择、月份滑动/按钮切换和“回到今天”。
- 点击日期后，在月历下方按时间顺序展示当天全部任务；每个任务独立成框，可继续进入当天任务页。
- 月历支持展开和收起；收起后显示月份标题、展开按钮以及选中日期所在的一整周日期。
- 当天页面依次展示复习卡片专区、新任务卡片专区，以及位于最下方的已完成卡片专区。
- 复习与新建专区均支持卡片新增、读取、编辑、删除和完成。
- 月历圆点数量统计新任务与复习任务的总数。
- 任务详情按创建顺序展示纵向连续内容卡片，新卡片固定在底部。
- 每张内容卡片包含卡片目标、初始动作、验收标准，并支持展开、编辑和删除。
- 验收详情支持完成/取消完成，以及 0–4 五级掌握度；0 是有效已选状态。
- 原始任务完成后可开启 2、3、7 天复习；自动复习任务和手动复习任务不能继续派生复习链。
- 任意卡片标记完成后自动移入最下方的“已完成卡片专区”；取消完成后返回卡片原本所属专区。
- 右下角深色圆形加号可新建今天的任务卡片，标题与时间使用可滚动的底部大面板编辑，点击外部可返回日历。
- 界面统一使用“任务卡片 / 内容卡片”术语；日历预览卡片中可直接切换完成状态和间隔复习。
- 任务卡片上的“已完成 / 标记完成”和“添加到间隔复习”在同一行展示。
- 验收页可在验收标准下方添加学习快照，支持系统照片选择器和音频文件选择器。
- 快照文件复制到 App 专属 `学习快照` 目录，目录不存在时自动创建；无需存储权限。
- 点击照片可在 App 内放大查看，点击录音可在 App 内播放/暂停，点击普通文件可交给系统应用打开。
- 学习快照支持删除，数据库元数据和 App 本地文件会同步清理。
- 底部新增“学习日历 / 周总结”切换栏。
- 周总结支持按周切换，并在右侧进入详情；详情页可查阅本周全部任务卡片、打开任务详情。
- 周总结详情顶部支持上传、打开和删除 docx/pdf 文档。
- 周总结总页面显示当前查看月份内上传的全部周总结报告，可直接打开或进入对应周详情。
- 验收页“学习快照”右侧新增“错误记录”，支持多个错误记录卡片增删改查。
- 错误记录卡片包含必填错误点和选填错误描述，并可上传、查看和删除多张截图。
- 新建错误记录卡片时即可预选照片和普通文件，保存卡片时一并导入；附件失败会回滚新建记录。
- 所有 CRUD、完成状态、掌握度和复习链均持久化到本机 Room 数据库。
- 底部增加“电脑同步”入口；同步前校验电脑地址、端口和 6 位配对码。
- 底部导航使用“学习日历 / 周总结 / 电脑同步 / 任务完成概况”四个图标，不显示文字标签。
- 任务完成概况支持逐日切换和日期选择，分别计算新建任务与复习任务完成率。
- 当天任务饼图按任务卡显示，点击扇形或任务卡可查看该任务的内容卡片数量。
- 同步包包含全部任务卡、内容卡、完成状态、掌握度、学习快照、错误记录、周总结和实际附件文件。
- 首次配对成功后保存长期同步凭证；之后任务、内容卡、验收、错误记录、周总结或附件发生变化时，会自动向同一台电脑推送最新数据。
- 电脑同步仅新增 `INTERNET` 与 `ACCESS_LOCAL_NETWORK` 权限；照片和文件选择继续使用系统选择器，不申请存储、相机、日历或通知权限。

## 数据模型

- `StudyTaskEntity`
  - 稳定 UUID；标题；日期；可选时间；专区；任务完成状态；是否开启间隔复习；系统创建日期与创建时间。
  - 来源类型：原始任务、自动复习任务、手动复习任务。
  - 自动复习任务保存 `sourceTaskId + reviewSequence`，数据库对两者建立唯一索引。
- `TaskContentCardEntity`
  - 任务外键、三个内容字段、创建时间、稳定 `sortOrder`、验收完成状态、可空掌握度。
  - 编辑不会改变 `sortOrder`；任务或卡片删除时使用外键级联。
- `LearningSnapshotEntity`
  - 关联内容卡片，保存照片/录音类型、原文件名、App 内相对路径和创建时间。
- `ErrorRecordEntity / ErrorScreenshotEntity`
  - 错误记录关联内容卡片；截图关联错误记录并通过文件外键级联时清理。
- `WeekSummaryDocumentEntity`
  - 按周起始日期保存 docx/pdf 文档元数据。
- Room 数据库升级到版本 4，并提供版本 1 → 2 → 3 → 4 的非破坏性迁移。
- `AppMetadataEntity`
  - 记录 V2 示例数据是否已经初始化，避免用户清空任务后重新启动又被填入示例。

DAO 负责查询与更新，`RoomStudyTaskRepository` 负责事务和领域转换。UI 只通过 Repository 与 ViewModel 接收 Flow 数据。

电脑同步使用独立的数据层：`ComputerSyncRepository` 在一个数据库读取事务中导出全部业务表，生成 `manifest.json`，并写入所有快照、错误记录附件和周总结文件。格式版本当前为 `1`。

## 间隔复习规则

实际完成并开启复习的当天算第 1 天：

| 复习序号 | 日期 |
|---:|---|
| 第 2 天 | 实际学习日期 `D + 1` |
| 第 3 天 | 实际学习日期 `D + 2` |
| 第 7 天 | 实际学习日期 `D + 6` |

开启复习时，在一个 Room 事务中：

1. 标记原始任务已开启复习，原始任务保留为第 1 天记录；
2. 创建缺失的第 2、3、7 天任务；
3. 将源任务标题、时间和内容卡片按原顺序复制为独立快照；
4. 若记录已存在则复用，避免重复生成。

关闭复习、取消已完成状态和删除原始任务都会清理关联自动复习任务；删除单个自动复习任务只影响当前实例。旧版本产生的复习链会在升级后自动补建缺失的第二天，并统一重排到正确的第 2、3、7 天。

## 荣耀手机竖屏与无障碍

- 竖屏锁定，系统栏使用 edge-to-edge 与 `WindowInsets.safeDrawing` 避让状态栏、屏幕圆角和手势导航。
- 内容页使用可滚动 `LazyColumn`；任务详情底部固定添加按钮额外避让导航手势区域。
- 日期触控单元与其他点击入口均至少 48dp。
- 360dp 宽度下日期列仍不小于 48dp，兼容 360–430dp。
- 长标题、日期、时间、验收文本和卡片字段不限单行，可在窄屏/大字体下换行增高。
- 任务完成、复习状态和验收状态使用文字与控件双重表达，不只依赖颜色。
- 日期、任务完成、间隔复习、编辑、删除、验收详情和五级掌握度均提供中文无障碍语义。
- 新页面提供 360dp 和 1.8 倍字体缩放 Compose Preview。
